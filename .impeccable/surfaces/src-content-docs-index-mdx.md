# Aura documentation

Mode: Read. Targets: documentation homepage, shared shell, and all article pages.
Audience: engineering, security, and compliance teams looking up Aura workflows.
The user approved applying and documenting the Aura-led Linuscent brand while
preserving product copy, navigation, search, and theme selection.

## Direction contract

THESIS: A Linuscent reference library, not a marketing landing page. Carry the
Aura identity through a precise frame and keep the reading column quiet.

OWN-WORLD: Website-derived near-black and navy surfaces, cyan interaction,
Space Grotesk headings, Inter reading text, and JetBrains Mono code. Keep the
official red Linuscent mark untouched. Light mode uses the same cyan identity
with darker ink values chosen for contrast.

STORY: Find a topic, recognize the current location, read a task, and follow a
related guide without learning a new navigation model.

FIRST VIEWPORT: A compact branded masthead and existing search. Articles retain
a navigation rail, a readable central column, and desktop contents. The homepage
retains its title, introduction, actions, and six topic links, presented as a
compact reading index rather than oversized marketing cards.

FORM: User-pinned existing Linuscent Aura identity, adapted to Read mode; no
concept lottery or invented visual world. The signature interaction is a quiet
cyan hover/focus treatment shared by navigation, topic links, and search.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Scope boundaries

No new claims, sections, landing-page narrative, decorative motion, canvas,
background photography, or dependency on the parent repository at runtime.
New fonts are self-hosted via Fontsource. Existing screenshots and the source
website establish visual authority; no new raster artwork is required.
