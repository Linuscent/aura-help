# Starlight integration notes

Documentation content lives in `src/content/docs/` — the single source of truth. Edit pages there directly; there is no separate `docs/` directory.

## Sidebar strategy

The pages include `sidebar.order` metadata, and the Starlight sidebar uses autogenerated directory groups for each documentation section (configured in `astro.config.mjs`).

Recommended section order:

1. Getting Started
2. Products and Releases
3. Inventory
4. SBOM
5. Risks
6. Evidence
7. Compliance
8. Integrations
9. Licenses and Policies
10. Workspace and Account
11. Troubleshooting

## Heading convention

Do not add a Markdown `#` heading that duplicates the page title. Starlight uses the frontmatter `title` as the page's top-level title.

## Links

Internal documentation links are route-based and extensionless (for example `/getting-started/what-is-aura`) so the content does not depend on `.md` source URLs.

## Homepage

The homepage (`src/content/docs/index.mdx`) uses Starlight's splash template with a custom hero and a "Popular Topics" card grid.
