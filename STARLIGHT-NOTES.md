# Starlight integration notes

The files in `docs/` are already formatted for Starlight content.

## Expected Starlight location

After creating the Astro/Starlight application, copy the documentation tree:

```bash
mkdir -p src/content/docs
cp -R docs/. src/content/docs/
```

## Sidebar strategy

The pages include `sidebar.order` metadata. A Starlight sidebar can therefore use autogenerated directory groups for each documentation section.

Recommended section order:

1. Getting Started
2. Products and Releases
3. Inventory
4. SBOM
5. Risks
6. Evidence
7. Compliance
8. Integrations
9. Licenses and Policies
10. Workspace and Account
11. Troubleshooting

## Heading convention

Do not add a Markdown `#` heading that duplicates the page title. Starlight uses the frontmatter `title` as the page's top-level title.

## Links

Internal documentation links are route-based and extensionless so the content does not depend on `.md` source URLs.
