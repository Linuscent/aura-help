Integration issues can occur when Aura connects with external systems or
workflows.

## Common Causes

Possible causes include:

-   Incorrect configuration
-   Missing permissions
-   Invalid connection details
-   Unsupported data format

## Troubleshooting Steps

1.  Verify integration settings.
2.  Confirm required access permissions.
3.  Check transferred data.
4.  Review available error information.

## Further Help

If the issue continues, provide relevant error details and integration
context when requesting support.
