Aura uses permissions to control what users can access and manage within
a workspace.

## Permissions

Permissions help organizations control access to:

-   Products
-   Security information
-   Workspace settings
-   Collaboration features

## Managing Access

Workspace administrators can manage user access according to their
organization requirements.

## Important Note

Available roles and permission options depend on the configured Aura
environment.
