Notifications and routing help teams direct relevant security
information to the appropriate users or workflows.

## Purpose

Teams can use notifications to:

-   Stay informed about security events
-   Route information to responsible teams
-   Support response workflows

## Configuration

Available notification options depend on the configured Aura
environment.
