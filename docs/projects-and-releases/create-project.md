# Create a project

Create a project before uploading an SBOM.

A project is used to organise its releases, SBOMs, inventory, and related security information.

## Before you begin

You need:

- access to an Aura workspace;
- permission to create projects in that workspace.

## Create a project

1. Sign in to Aura.
2. Open the workspace where you want to create the project.
3. Select **Projects** from the navigation.
4. Select **New**.
5. In the **New Project** dialog, enter a project name.
6. Optionally enter a project description.
7. Select **Create Project**.

The new project appears in the project list.

## What happens next?

After creating the project, open it to:

- upload an SBOM;
- create the project's first release;
- review release-level inventory;
- review related security information.

A release is not created when the project itself is created.

Aura creates a release after a supported SBOM is successfully uploaded to the project.

## Project naming

Choose a name that clearly identifies the software or product area represented by the project.

Use naming that remains understandable across engineering, security, product, and compliance teams.
