API ingestion allows Aura to receive security-related data from
connected systems.

It helps organizations integrate Aura into existing security workflows
and automation pipelines.

## Purpose

API-based ingestion can be used to:

-   Send structured security information to Aura
-   Connect external workflows
-   Automate data transfer

## Availability

Available ingestion capabilities depend on the configured Aura
environment and integrations.
