Remediation is the process of addressing security findings identified in
a product release.

## Common Remediation Actions

Teams may:

-   Update affected dependencies
-   Replace vulnerable components
-   Review mitigation options
-   Document decisions

## Release Updates

After changes are made, a new SBOM upload can create an updated release
snapshot for analysis.
