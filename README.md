# Aura Help

User help and documentation for Linuscent Aura.

## Purpose

This repository contains user-facing help content for Aura.

The documentation is maintained in Markdown so the content remains independent of the documentation generator and can be reviewed, edited, and versioned directly in Git.

## Documentation structure

Help content is located in the `docs/` directory.

Current sections include:

- Getting Started
- Projects and Releases
- SBOM
- Inventory
- Risks
- Licenses and Policies
- Compliance
- Integrations
- Workspace and Account
- Troubleshooting

## Content approach

The documentation is designed to be:

- task-oriented;
- easy to search;
- understandable for both technical and non-technical users;
- based on real Aura workflows;
- consistent with the terminology used in the Aura interface;
- explicit about prerequisites, expected results, and troubleshooting.

## Documentation generator

The content is currently maintained as plain Markdown.

A documentation generator will be added after the initial information architecture and core content have been reviewed.

Astro/Starlight and MkDocs are currently under consideration.

## Contributing

When adding or updating documentation:

- use lowercase file names;
- use kebab-case for file names;
- use the same terminology as the Aura interface;
- keep article titles clear and task-oriented;
- avoid documenting unconfirmed product behaviour;
- link related articles where useful;
- keep terminology consistent across the documentation.
